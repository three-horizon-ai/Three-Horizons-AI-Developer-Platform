# Infrastructure Templates

This directory contains infrastructure templates for deploying the Three Horizons Platform components.

## Available Templates

- **Kubernetes Templates**: Configuration templates for Kubernetes resources
- **Terraform Templates**: Terraform modules for infrastructure deployment
- **Bicep Templates**: Azure Bicep modules for Azure infrastructure

## Usage

Reference these templates in your implementation to ensure consistent infrastructure deployment across environments.

## Directory Structure

- `/kubernetes/`: Kubernetes manifests and configurations
- `/terraform/`: Terraform modules and configurations
- `/bicep/`: Azure Bicep templates
