# Scripts Directory

This directory contains automation scripts for the Three Horizons Platform.

## Available Scripts

### update_templates_to_resources.py
Updates all references from `templates/` to `resources/` across the repository.

```bash
python3 update_templates_to_resources.py
```

## Adding New Scripts

When adding new automation scripts:
1. Create descriptive names
2. Include documentation in the script
3. Update this README with usage instructions
4. Make scripts executable: `chmod +x script_name.py`
