# Three Horizons Platform - Application Examples

This directory contains sample applications that demonstrate the use of various patterns, templates, and capabilities of the Three Horizons Platform. These examples can help you understand best practices for developing applications on the platform.

## Available Examples

### Web Applications

- [**react-typescript-app**](./react-typescript-app): A React/TypeScript frontend application with Azure AD authentication
- [**node-express-api**](./node-express-api): A Node.js Express API with OpenAPI documentation

### Microservices

- [**java-spring-service**](./java-spring-service): A Spring Boot microservice with containerization
- [**dotnet-api-service**](./dotnet-api-service): A .NET Core API service with health checks

### Data Processing

- [**python-data-processor**](./python-data-processor): A Python-based data processing application

## Using the Examples

Each example includes:

1. **README.md**: Detailed documentation about the application
2. **Source code**: Complete working application code
3. **Configuration files**: Required configuration for deployment
4. **CI/CD pipelines**: GitHub Actions workflow examples

## Getting Started

To run any of these examples:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-organization/three-horizons-platform.git
   ```

2. Navigate to the desired example directory:
   ```bash
   cd examples/applications/react-typescript-app
   ```

3. Follow the specific instructions in the example's README.md file.

## Contributing Examples

We encourage contributions of new examples that demonstrate effective use of the Three Horizons Platform. To contribute:

1. Fork the repository
2. Create your example in a new directory under `examples/applications/`
3. Include comprehensive documentation
4. Ensure the example follows platform best practices
5. Submit a pull request

For more information on contribution guidelines, see the [Contribution Guide](../../docs/documentation/contribution/contributing.md).
