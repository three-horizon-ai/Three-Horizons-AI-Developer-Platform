Architecture Overview

The Three Horizons Platform integrates three key technology pillars into a cohesive ecosystem:

Azure

  • Azure Kubernetes Service (AKS)
  • Azure Database PostgreSQL
  • Azure Container Registry (ACR)

OpenShift

  • Developer Hub / Backstage Portal
  • Container Platform Orchestration
  • Service Mesh & API Management

GitHub

  • Actions CI/CD Pipelines
  • Repositories / Source Control
  • Advanced Security & CodeQL

This architecture showcases how Microsoft Azure, Red Hat OpenShift, and GitHub Enterprise integrate to create a superior developer experience.
