# Horizon 1 Foundation - Demo Documentation

This directory contains comprehensive demo scenarios for validating the foundational capabilities of the Three Horizons AI Developer Platform.

## Demo Scenarios

### [001-basic-deployment-demo.md](001-basic-deployment-demo.md)

- Basic Azure infrastructure deployment
- Core security setup validation
- Basic monitoring setup

### [002-github-integration-demo.md](002-github-integration-demo.md)

- GitHub repository setup
- Basic CI/CD pipeline demonstration
- Code integration workflows

### [003-developer-hub-demo.md](003-developer-hub-demo.md)

- Developer Hub deployment and configuration
- Portal functionality demonstration
- Basic developer workflows

### [004-end-to-end-demo.md](004-end-to-end-demo.md)

- Complete foundational platform demonstration
- Sample application deployment
- User journey validation

## Prerequisites

Before running any demo scenarios, ensure you have:

- Azure subscription with required permissions
- GitHub account and organization setup
- Azure CLI and required tools installed
- Access to the platform's Azure resources

## Demo Execution Order

For first-time demonstrations, follow this recommended order:

1. **Basic Deployment Demo** - Validates core infrastructure
2. **GitHub Integration Demo** - Establishes source control and CI/CD
3. **Developer Hub Demo** - Showcases developer experience
4. **End-to-End Demo** - Demonstrates complete workflow

## Success Criteria

Each demo includes specific success criteria to validate:

- ✅ Infrastructure provisioned correctly
- ✅ Security policies applied
- ✅ CI/CD pipelines functional
- ✅ Developer Hub accessible and operational
- ✅ Sample applications deployable
