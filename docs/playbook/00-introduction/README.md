# Introduction to the Three Horizons Platform

**Navigation**: [Home](../README.md) > Introduction

## Platform Overview

The Three Horizons Platform is an integrated solution that combines Microsoft Azure, Red Hat Developer Hub, and GitHub Enterprise to create a unified and modern developer experience. This platform is designed to accelerate innovation while maintaining governance, security, and quality.

![Platform Overview](../../../assets/diagrams/introduction/three-horizons-architecture.svg)

## The Three Technology Pillars

The platform is built on three fundamental technology pillars:

1. **Microsoft Azure** - Provides cloud infrastructure and services (AKS/ARO)
2. **Red Hat Developer Hub** - Developer portal and experience platform
3. **GitHub Enterprise** - Source control, collaboration, and CI/CD

The integration of these three components creates a synergy that is greater than the sum of its parts, providing a superior development experience.

## Key Benefits

- **🚀 Accelerated Onboarding** - Developers become productive in minutes
- **🧠 Reduced Cognitive Load** - Golden Paths guide developers through common workflows
- **🤖 AI-Assisted Development** - GitHub Copilot integration enhances productivity
- **🔒 Integrated Security** - Unified security controls across the platform
- **📈 Streamlined Lifecycle** - Seamless transitions from development to deployment
