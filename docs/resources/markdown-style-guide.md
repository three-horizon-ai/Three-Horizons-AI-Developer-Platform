# <span style="color: #0366d6;">📘 Markdown Formatting Guide</span>

Este guia define as convenções de formatação Markdown para documentação no repositório.

## <span style="color: #0366d6;">🔹 Formatação Básica</span>

- **Negrito**: Use `**texto**` para enfatizar fortemente
- *Itálico*: Use `*texto*` para enfatizar levemente
- `Código inline`: Use `` `código` `` para código inline

## <span style="color: #0366d6;">🔹 Cabeçalhos</span>

Utilize cabeçalhos para organizar seu conteúdo:

```markdown
# <span style="color: #0366d6;">🔹 Título Principal (H1)</span>
## <span style="color: #0366d6;">🔹 Seção (H2)</span>
### <span style="color: #0366d6;">Subseção (H3)</span>
#### Sub-subseção (H4)
```

## <span style="color: #0366d6;">🔹 Listas</span>

### <span style="color: #0366d6;">Listas não ordenadas</span>
- Item 1
- Item 2
  - Subitem 2.1
  - Subitem 2.2

### <span style="color: #0366d6;">Listas ordenadas</span>
1. Primeiro passo
2. Segundo passo
   1. Subpasso 2.1
   2. Subpasso 2.2

## <span style="color: #0366d6;">🔹 Blocos de código</span>

```bash
# <span style="color: #0366d6;">🔹 Exemplo de código bash</span>
echo "Hello World"
```

```python
# <span style="color: #0366d6;">🔹 Exemplo de código python</span>
print("Hello World")
```
