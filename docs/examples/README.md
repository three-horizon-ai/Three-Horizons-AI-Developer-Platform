# Three Horizons Platform Examples

**Navigation:** [Home](../../README.md) > [Documentation Map](../DOCUMENTATION_MAP.md) > Examples

## Your Implementation Resource Journey

Welcome to the Examples section of the Three Horizons Platform documentation. This collection of practical examples and templates demonstrates how to implement various components and capabilities of the platform in real-world scenarios.

Each example is designed to accelerate your implementation journey by providing ready-to-use patterns that have been tested and refined. Whether you're setting up CI/CD pipelines, configuring monitoring dashboards, or implementing integration workflows, these examples will help you achieve results quickly while following best practices.

## Available Example Categories

- [GitHub Actions Examples](github-actions/README.md) - Workflow templates for automated CI/CD pipelines
- Pipeline configurations for various application types
- Deployment automation examples

### Integration and Automation Examples

- [Logic Apps Examples](logic-apps/README.md) - Azure Logic Apps for workflow automation

### Monitoring and Observability Examples

- [Dashboard Examples](dashboards/README.md) - Azure Dashboard templates for monitoring
- [KQL Query Examples](kql-queries/README.md) - Kusto queries for log analytics
- Grafana and Prometheus configurations

### Application Examples

- Microservice application examples
- API designs and implementations
- Frontend application patterns

## Using These Examples

Each example includes:

1. **Complete implementation files** - Ready to use in your environment
2. **Step-by-step guidance** - Clear instructions for implementation
3. **Customization options** - Ways to adapt examples to your specific needs
4. **Best practices** - Recommendations for implementation
5. **Integration points** - How examples connect with other platform components

To make the best use of these examples:

1. Start with the [Implementation Guide](../2-implementation-guide/README.md) to understand the context
2. Review the [Architecture Overview](../1-architecture/README.md) to see how examples fit into the platform
3. Choose examples that match your current implementation phase
4. Customize the examples to fit your specific environment and requirements
5. Use the [GitHub Copilot Integration](../getting-started/github-copilot-integration.md) for further assistance

## Implementation Path

For a successful implementation, we recommend following this path through the examples:

1. Begin with **GitHub Actions** examples to establish your CI/CD foundation
2. Add **Logic Apps** for automation and integration
3. Implement **Dashboard** examples for monitoring and observability 
4. Use **KQL Queries** to enhance your monitoring capabilities
5. Apply **Application** examples as templates for your custom applications

This progression builds a solid foundation while expanding capabilities in a structured manner.
