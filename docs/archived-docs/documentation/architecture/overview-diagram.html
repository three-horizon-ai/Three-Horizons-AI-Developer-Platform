Three Horizons Integration Platform

The Three Horizons Platform integrates three key technology pillars into a cohesive ecosystem that delivers a superior developer experience:

Microsoft Azure

Provides the infrastructure and platform services:

  • Azure Kubernetes Service (AKS)
  • Azure Red Hat OpenShift (ARO)
  • Azure Database Services
  • Azure Active Directory

Red Hat Developer Hub

Creates a centralized developer portal:

  • Golden Path Templates
  • Service Catalog
  • Developer Documentation
  • Self-Service Tools

GitHub Enterprise

Enables DevOps and security capabilities:

  • Source Code Management
  • CI/CD Pipelines (Actions)
  • Advanced Security (CodeQL)
  • GitHub Copilot
