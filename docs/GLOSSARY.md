# <span style="color: #0366d6;">📘 Three Horizons Platform Glossary</span>

**Navigation:** [Home](../README.md) > [Documentation Map](DOCUMENTATION_MAP.md) > Glossary

This glossary provides definitions for common terms used throughout the Three Horizons Platform documentation.

## <span style="color: #0366d6;">A</span>

### Azure Kubernetes Service (AKS)
Microsoft's managed Kubernetes service that simplifies the deployment, management, and operations of Kubernetes.

### Azure Red Hat OpenShift (ARO)
A jointly managed enterprise-grade Kubernetes service on Azure, powered by Red Hat OpenShift.

### Azure Active Directory (AAD)
Microsoft's enterprise identity service that provides single sign-on, multi-factor authentication, and conditional access.

## <span style="color: #0366d6;">D</span>

### Developer Hub
The central developer portal in the Three Horizons Platform that provides a unified interface for developers to discover and use platform tools and services.

### DevSecOps
An approach to culture, automation, and platform design that integrates security as a shared responsibility throughout the entire IT lifecycle.

## <span style="color: #0366d6;">G</span>

### GitOps
A way of implementing Continuous Deployment for cloud-native applications using Git as the single source of truth for declarative infrastructure and applications.

### Golden Path
A standardized, supported workflow that guides developers through specific tasks, such as creating a new application or deploying a service. Golden Paths remove cognitive burden from developers by providing recommended, tested paths.

### GitHub Enterprise
The enterprise version of GitHub that includes advanced security, compliance, and deployment controls for large organizations.

## <span style="color: #0366d6;">I</span>

### Inner Loop Development
The development workflow that runs on a developer's local machine, where code is written, tested, and debugged before being committed.

## <span style="color: #0366d6;">K</span>

### Kubernetes
An open-source container orchestration platform for automating deployment, scaling, and operations of application containers.

## <span style="color: #0366d6;">O</span>

### OpenShift
Red Hat's enterprise Kubernetes platform that provides a consistent foundation to deliver applications in hybrid, multicloud environments.

### Outer Loop Deployment
The deployment workflow that begins after code is committed, including CI/CD pipelines, testing, and promotion to production environments.

## <span style="color: #0366d6;">R</span>

### RBAC (Role-Based Access Control)
A method of regulating access to resources based on the roles of individual users within an organization.

### Red Hat Developer Hub
A platform for creating developer portals that provides a centralized place for software catalogs, documentation, and tools.

## <span style="color: #0366d6;">S</span>

### Service Mesh
A dedicated infrastructure layer that controls service-to-service communication over a network, typically implemented as a set of network proxies deployed alongside application code.

### Service Principal
An identity created for use with applications, hosted services, and automated tools to access Azure resources.

## <span style="color: #0366d6;">T</span>

### Three Horizons Model
A framework for managing innovation that categorizes initiatives into three "horizons" based on their distance from the core business.
